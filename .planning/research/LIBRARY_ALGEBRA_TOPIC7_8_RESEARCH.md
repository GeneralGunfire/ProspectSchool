## Topic 7 — Solving Quadratic Equations

**Scope:** factorisation-based solving only (common factor, trinomial,
difference of squares), zero-product principle, rearranging to `ax²+bx+c=0`
first. Repeated roots and "no real solution" cases are touched informally.
**Out of scope** (inferred): quadratic formula, completing the square as a
method, complex/non-real roots, graph-based solving — all Grade 11+.

**Sequence:** connect factorised expressions → equations ("when does this
equal 0?") → introduce zero-product principle with numeric analogy first →
solve already-factorable trinomials in standard form → equations needing
rearrangement to `=0` first → common-factor/difference-of-squares forms →
repeated roots and no-real-solution cases explicitly.

**Misconceptions (10, condensed to the ones with the clearest feedback
branches):**
1. Not setting the equation to zero before factorising.
2. Misapplying zero-product to a nonzero product (e.g. `(x-2)(x-3)=6` → each factor = 6).
3. Sign errors during factorisation carried into solving.
4. Losing one of the two roots (stopping after the first).
5. Dividing both sides by a variable factor, losing a root (e.g. `x(x-3)=0` → divide by x → misses x=0).
6. Treating a quadratic like a linear equation (trying to isolate x directly).
7. Mishandling repeated roots (reporting "x=3 and x=3" as two separate solutions, or forcing a second distinct root).
8. Not checking solutions back in the original equation.

**Assessment shape:** numeric-entry factorisation-solving; equations needing
rearrangement first; mixed factorisation-pattern items; "how many solutions"
conceptual items; MCQ targeting lost-root/sign-error/divide-by-x distractors.

**Opening hook:** "Factorisation as a tool for solving" — reframe the
already-learned factorising skill as answering "when does this equal zero?",
tying to real contexts (profit = 0, ball hits ground).

## Topic 8 — Solving Simultaneous Equations

**Scope:** two linear equations in two unknowns, via substitution and
elimination; basic graphical intuition (intersection point). **Out of scope**
(inferred): linear-quadratic systems as a standard requirement (enrichment
only), 3-variable systems, formal solution-type classification beyond
recognising unique/none/infinite.

**Sequence:** conceptual start (a pair of values satisfying two rules at
once) → substitution first, starting with one equation already solved for a
variable → elimination once substitution is comfortable, starting with
aligned coefficients before requiring scaling → explicit compare/contrast of
when to use which method → "no solution"/"infinitely many" cases explained
via contradiction (`0=3`) vs. identity (`0=0`), tied to parallel vs.
coincident lines.

**Misconceptions (10, condensed):**
1. Substitution sign/bracket errors (e.g. forgetting brackets: `3y` → `3·2x-3` instead of `3(2x-3)`).
2. Picking the harder equation to solve for a variable first (avoidable complexity, not incorrect per se — light-touch note only).
3. Stopping after finding one variable, forgetting to back-substitute.
4. Checking a solution in only one of the two original equations.
5. Not scaling every term when multiplying an equation for elimination.
6. Arithmetic slips when adding/subtracting to eliminate.
7. Eliminating the wrong variable / misaligning coefficients so nothing cancels.
8. Confusing "no solution" (contradiction, parallel lines) with "infinite solutions" (identity, same line).

**Assessment shape:** numeric-entry substitution systems; numeric-entry
elimination systems (including required scaling); mixed-method items;
solution-type identification with brief justification; MCQ on typical errors.

**Opening hook:** "When two rules must be true at once" — a pricing/rate
context where two conditions must hold simultaneously, tying directly to the
existing "solve one equation" skill extended to two at once.

**Common design principle for both:** each topic is one existing skill
(factorisation / linear solving) plus exactly one or two new conceptual
pivots — highlight and contrast those pivots against prior knowledge rather
than treating the topic as an entirely new bag of tricks.
