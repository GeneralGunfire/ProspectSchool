icon-master.png is generated by `node scripts/icon-master.mjs`, which composites
public/logo-dark-mode.png (the real brand mark) onto a dark rounded-square
plate (matching the brand's #050708 dark accent), scaled to ~70% so it has
margin and stays legible down to 16px. Re-run that script if
logo-dark-mode.png changes, or edit scripts/icon-master.mjs to change the
plate style / logo scale.

32x32.png, 128x128.png, and 128x128@2x.png here are derived from
icon-master.png via `npx @tauri-apps/cli icon src-tauri/icons/icon-master.png`.

icon.ico is intentionally not committed — the GitHub Actions Windows build
step runs the same `tauri-apps/cli icon` command before bundling, which
generates a correct multi-resolution icon.ico directly into this folder.
Run the same command locally before a local `tauri build` if you need
icon.ico on disk.
